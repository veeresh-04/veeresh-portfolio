MRI to FDG-PET Synthesis using Latent Diffusion Models

  • Developed a 3-stage pipeline — VAE, conditioned latent DDPM, and Refiner — to synthesize FDG-PET scans from MRI for Alzheimer's disease research on the ADNI dataset, achieving SSIM of 0.8464 and PSNR of 19.65 dB.

  • Conducted multi-level explainability analysis using GradCAM and ROI-level error maps, revealing statistically significant synthesis difficulty in the left hippocampus across diagnostic groups.

Real-Time Multi-Client File Transfer & Verification

PythonAsyncIOTCP SocketsSHA-256CRC32

Multi-client file transfer system built with Python AsyncIO and TCP sockets. A single event loop handles 100+ concurrent clients; files are split into 64 KB chunks, each tagged with a sequence number, client ID, and CRC32. Network faults — dropped packets, corrupted payloads, out-of-order delivery — are simulated with full retransmission logic.

  • Async TCP server handles 100+ concurrent clients on a single event loop with no thread overhead; each client session is fully isolated so one failure never affects others.
  • Per-chunk CRC32 verification and seq_num-driven ACK/NACK retransmission — the server never advances until the correct chunk is confirmed.
  • End-to-end SHA-256 integrity check after full reassembly; three configurable fault injectors (packet drop, payload corruption, out-of-order delivery) with stress-test tooling and 46 unit + integration + concurrency tests.
